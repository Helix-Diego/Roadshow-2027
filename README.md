# Helix Arena

Presentación interactiva del centro de alto rendimiento Helix Arena y del recorrido de demostración de BMC Helix.

## Abrir la presentación

Abre `index.html` en un navegador con WebGL. La web no requiere instalación ni compilación.

También puedes servir esta carpeta con un servidor HTTP local.

## Controles

- La vista principal recorre automáticamente las instalaciones.
- **Siguiente zona** adelanta el recorrido.
- **Mostrar red del campus** alterna entre la visita y la topología.
- **Modo escenario** abre las diapositivas de la demostración.
- **Anterior**, **Siguiente** y las flechas del teclado cambian de diapositiva.
- **Pantalla completa** permite entrar y salir. También puedes salir con Esc.

## Contenido

La presentación incluye Helix Dashboards, la red de AtletaPro, AIOps y HelixGPT, la war room de Teams con OpsWarmer, Change Coordinator, Knowledge Curator y Major Incident Report, Problem Solver, onboarding, Service Optimizer y Agent Outcomes.

El escenario representa el fallo del router BB-R1-SPBR y un cambio de firmware previo a la aplicación de QoS. Los sketches y datos ilustran la historia de la demo y no se conectan a sistemas de producción.

## Archivos

- `index.html` contiene la interfaz, estilos y sketches.
- `arena.js` contiene el recorrido, la maqueta y los estados de la presentación.
- `helix-arena.png` es el logo proporcionado para la presentación.
